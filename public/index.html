점검 결과

대상 로그인 연속 실패 업무 시간 외 접근 비인가 IP 검토 다수 IP 접근 검토 다운로드 행위 비인가 접속 비인가 권한 행위 로그 누락 과다 조회 보관기간 비고

📋 사용 가이드

점검 기준:

  • 로그인 연속 실패: 20분 내 5회 이상 실패
  • 업무시간 외 접근: 00시~06시 사이 접근
  • 다수 IP 접근: 한 계정당 2개 이상 IP 사용
  • 다운로드 행위: 다운로드/download/export/엑셀/CSV/내보내기 키워드 포함
💡 엑셀에서 복사할 때 헤더 포함해도 자동으로 제외됩니다. 탭으로 구분된 데이터를 그대로 붙여넣으세요!

월간 점검 리포트

해당 월 접속기록 구글드라이브 폴더(agit-automation state.json에 등록된)에서 자동으로 가져옵니다.

"@" 없이 아이디만 입력하세요. 여러 명은 쉼표로 구분 (예: han.b, louis.l) - 발행 시 "@han.b @louis.l"로 변환됩니다.

계정명 → LDAP 매핑

로그에 기록된 계정명이 실제 LDAP과 다른 경우(예: 로그엔 "elvin", 실제 LDAP은 "elvin.h") 여기에 등록해두면 리포트/소명 요청 생성 시 자동으로 변환됩니다. 등록·수정 후에는 리포트를 다시 불러와야 반영됩니다.
